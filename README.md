# Izlio site

Static site for the Izlio app. Plain HTML and one CSS file. No build step.

## Publish with GitHub Pages

1. Create a GitHub repository named `izlio`.
2. Push this folder to the `main` branch.
3. Open Settings > Pages. Choose Source: Deploy from a branch. Choose branch `main` and folder `/ (root)`. Save.
4. The site goes live at `https://<user>.github.io/izlio/`.

All links are relative, so the project path works.

## Before you publish

Replace these placeholders in every page (English and `tr/`): `[COMPANY NAME]`, `[ADDRESS]`, `[SUPPORT EMAIL]`.
